# Contoh bank soal kelas 6

Contoh orisinal berisi 10 soal Matematika dan 10 soal Bahasa Indonesia. Keenam tipe pertanyaan didemonstrasikan: PG, PG Kompleks, Isian Singkat, Menjodohkan, Benar Salah, dan Sesuai Tidak Sesuai. Setiap sekolah contoh memiliki dua paket berisi masing-masing 10 soal.

Contoh sudah dipasang di SCH-058 Sekolah Dasar Universal dan SCH-057 SD Strada Van Lith I. Guru dapat memeriksa soal melalui menu Bank Soal dan paket melalui tab Paket Soal.

Unduh berkas yang diperlukan:

- [20 soal kedua mapel](https://cbt58-admin-pusat-publik.closedmyna32.chatgpt.site/contoh-soal/kelas-6-semua-mapel.xlsx)
- [10 soal Matematika](https://cbt58-admin-pusat-publik.closedmyna32.chatgpt.site/contoh-soal/kelas-6-matematika.xlsx)
- [10 soal Bahasa Indonesia](https://cbt58-admin-pusat-publik.closedmyna32.chatgpt.site/contoh-soal/kelas-6-bahasa-indonesia.xlsx)
- [Template kosong dengan panduan format](https://cbt58-admin-pusat-publik.closedmyna32.chatgpt.site/contoh-soal/template-kosong.xlsx)

Di sekolah tujuan, daftarkan mapel bernama persis `Matematika` dan `Bahasa Indonesia`. Pilih **Bank Soal → Import Excel**, pilih file, periksa 20 soal valid, lalu tekan **Import**. Untuk mengambil salah satu mapel saja, gunakan file 10 soal yang sesuai. Impor menambahkan pertanyaan baru; hindari mengimpor ulang file yang sama agar tidak duplikat.

File gabungan memuat soal di sheet `Template_Soal` dan petunjuk di `Panduan`. Import memindahkan bank pertanyaan; paketnya dapat dibuat di tab Paket Soal dengan memilih 10 pertanyaan dari mapel yang sesuai. Berkas adalah contoh latihan yang dapat diedit guru sesuai kebutuhan kelas.

Kunci dan jumlah soal sudah dibaca ulang sesudah import melalui aplikasi. Bukti ada di `reports/demo-school-questions.json`. Sumber yang dapat diedit untuk membuat ulang contoh adalah `kelas-6.json`.
